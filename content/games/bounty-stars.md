Bounty stars is a rogue-like/RPG set in space, with a mixture of story-driven elements, crew battles and ship battles. 
I worked on all aspects of the game. In particular, I made tools for setting up the story elements and engineered the 
procedural way in which they are displayed in the game. I also set up the animation system, using animation override 
controllers to re-use a single animation state machine. I also set up the systems for generating procedural enemy characters. 
Published by DeNA, now sadly taken down following the closure of DeNA West.
