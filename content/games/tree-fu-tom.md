This game was made as an accompaniment to an episode where tree fu tom races in the “Conkerball Cup”. The game was made 
using html5 canvas and createjs. I was responsible for creating the pseudo-3d racing engine, which was a challenging 
but enjoyable task given the demands of the game and the limitations of html5 canvas.
